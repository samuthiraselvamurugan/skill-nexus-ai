# 🚀 SKILLNEXUS AI – Cinematic 3D Career Intelligence

**An AI-powered career guidance and personalized learning platform with an immersive 3D and VR-inspired experience.**

## 🌌 About the Project

SKILLNEXUS AI is a next-generation career intelligence platform designed to help students discover career opportunities, identify skill gaps, improve technical knowledge, and prepare for future jobs.

It combines artificial intelligence concepts, interactive learning, career recommendations, and cinematic 3D visual experiences into one platform.

## ✨ Key Features

- **3D Command Center:** Futuristic dashboard for monitoring learning progress and career readiness.
- **3D Skill Galaxy:** Visualize technical skills, proficiency levels, and skill gaps.
- **Career Explorer:** Discover suitable career paths based on skill alignment.
- **AI Mentor:** ChatGPT-style AI assistant for coding help, study plans, debugging, and career guidance.
- **Course Universe:** Interactive orbital course navigation with individual study rooms.
- **Smart Assessments:** Test knowledge and identify areas that need improvement.
- **Project Lab:** Explore practical project development.
- **Analytics Dashboard:** Monitor learning progress and readiness.
- **Six AI Agents:** Skill Analyzer, Career Advisor, Learning Planner, Assessment Evaluator, Progress Mentor, and Personal AI Mentor.
- **Immersive VR Mode:** VR-inspired spatial interface with WebXR support detection.
- **Responsive Interface:** Designed for an immersive desktop and mobile experience.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/SKILLNEXUS-AI.git
```

### 2. Open the Project

```bash
cd SKILLNEXUS-AI
```

### 3. Run the Application

Open `index.html` in your browser.

You can also use the VS Code Live Server extension.

**Note:** The project loads React, Three.js, Tailwind CSS, and Babel through external CDNs, so an internet connection is required.

## 🤖 AI Integration

SKILLNEXUS AI includes a built-in Smart Mentor response system and an optional live AI API connection.

Live AI integration supports an OpenAI-compatible chat completions endpoint.

For production deployment, API credentials should be handled securely through a backend server rather than exposed in browser code.
